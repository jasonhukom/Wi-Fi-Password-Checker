Set it up

three commands and you're running
1

Create a .env file

In the project folder, next to server.js, make a file named exactly .env and put the port in it:

PORT=3000
2

Install dependencies

From that same folder, run:

npm install
3

Start the server

Then run:

npm start

Open http://localhost:3000 in your browser — that's the checker.
